= Ver el ahorro de espacio de ONTAP con archivos FlexClone y FlexClone LUNs
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible ver el porcentaje de espacio en disco ahorrado por el uso compartido de bloques en un volumen que contiene archivos de FlexClone y LUN de FlexClone. Puede hacerlo como parte de la planificación de la capacidad.

.Pasos
. Consulta el ahorro de espacio conseguido gracias a los archivos FlexClone y los LUN de FlexClone:
+
[source, cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
Si ejecutas este comando en un volumen FlexVol con la deduplicación activada, podrás ver el espacio ahorrado tanto por la deduplicación como por los archivos y las LUN de FlexClone.

====

= Habilitar la compatibilidad de ONTAP con el tamaño máximo de directorio grande
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partir de ONTAP 9.20.1, puedes habilitar y configurar la compatibilidad con un tamaño máximo de directorio mayor, ya sea al crear un volumen o al modificar uno ya existente. Esto permite que los directorios contengan hasta aproximadamente 25 millones de archivos, carpetas y otras entradas según un tamaño máximo de directorio de 4 GB.

[CAUTION]
====
Una vez aumentado el tamaño máximo del directorio, no es posible reducirlo sin volver a crear el directorio o los directorios afectados en el volumen.

====
.Antes de empezar
Antes de crear o modificar un volumen para que admita un tamaño máximo de directorio mayor, asegúrate de que eres administrador del clúster o de la SVM.



[[create-a-new-volume]]
== Cree un nuevo volumen

Puedes establecer un tamaño máximo mayor para el directorio al crear un nuevo volumen.

.Pasos
. Crea un volumen con la compatibilidad para el tamaño máximo de directorio más grande activada:
+
[source, cli]
----
volume create -vserver <svm_name> -volume <volume_name> -aggregate <aggr_name> -is-dir-index-transfer-enabled true
----
+
.Ejemplo
[listing]
----
volume create -vserver vs1 -volume big_dir1 -aggregate aggr1 -is-dir-index-transfer-enabled true
----
. Aumenta el tamaño máximo del directorio, hasta 4 GB:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.Ejemplo
[listing]
----
volume modify -vserver vs1 -volume big_dir1 -maxdir-size 4GB
----




[[modify-an-existing-volume]]
== Modifique un volumen existente

Puedes establecer un tamaño máximo mayor para el directorio modificando un volumen ya existente.

.Pasos
. Activa la compatibilidad con un tamaño máximo de directorio mayor en un volumen ya existente:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -is-dir-index-transfer-enabled true
----
+
.Ejemplo
[listing]
----
volume modify -vserver vs2 -volume data_vol -is-dir-index-transfer-enabled true
----
. Aumenta el tamaño máximo del directorio hasta 4 GB:
+
[source, cli]
----
volume modify -vserver <svm_name> -volume <volume_name> -maxdir-size <dir_size>
----
+
.Ejemplo
[listing]
----
volume modify -vserver vs2 -volume data_vol -maxdir-size 4GB
----

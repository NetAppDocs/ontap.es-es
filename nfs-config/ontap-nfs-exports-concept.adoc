= Más información sobre las exportaciones de NFS de ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP controla el acceso de clientes de NFS mediante políticas de exportación asignadas a volúmenes o qtrees. Cada política contiene reglas que definen qué clientes pueden acceder a los datos y qué permisos reciben.



[[export-policies-and-rules]]
== Reglas y políticas de exportación

Una SVM puede contener varias políticas de exportación. Cada política puede contener cero o más reglas de exportación que especifiquen coincidencias de clientes y permisos de acceso. Una política vacía deniega todo acceso. Puedes aplicar una política de exportación a más de un volumen.



[[apply-export-policies-to-volumes-and-qtrees]]
== Aplicar políticas de exportación a volúmenes y qtrees

Asigna una política de exportación a un volumen o a un qtree para controlar el acceso de los clientes de NFS a ese almacenamiento. Una política asignada a un volumen se aplica a los datos de dicho volumen; puedes asignar una política directamente a un qtree cuando necesites controlar el acceso a ese qtree.



[[volume-junction-paths]]
== Rutas de unión de volúmenes

Los volúmenes se montan en el espacio de nombres de SVM en una ruta de unión. Los clientes de NFS usan esta ruta para acceder a los datos del volumen. La ruta de unión puede ser diferente del nombre del volumen.

= Transición de la gestión de claves integrada a la gestión de claves externa en ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si quieres cambiar de la gestión de claves integrada a la gestión de claves externa, los pasos necesarios dependen del ámbito del gestor de claves. Para la SVM de administración (ámbito de clúster), debes desactivar la configuración de gestión de claves integrada antes de poder habilitar un gestor de claves externo. A partir de ONTAP 9.20.1, las SVM de datos pueden habilitar directamente un gestor de claves externo y ONTAP migra automáticamente las claves de cifrado de volumen de la SVM desde el gestor de claves de ámbito de administración al nuevo gestor de claves de la SVM de datos.

[NOTE]
====
A partir de ONTAP 9.20.1, esta tarea solo es necesaria cuando trasladas la SVM de administración de la gestión de claves integrada a la gestión de claves externa. Si estás configurando un gestor de claves externo para una SVM de datos, no necesitas desactivar primero la gestión de claves integrada.

====
.Antes de empezar
* Para el cifrado basado en hardware, debe restablecer las claves de datos de todas las unidades FIPS o SED a su valor predeterminado.
+
link:return-seds-unprotected-mode-task.html["Devolver una unidad FIPS o SED al modo sin protección"]

* Para el cifrado basado en software, debe descifrar todos los volúmenes.
+
link:unencrypt-volume-data-task.html["Descifrar los datos de volúmenes"]

* Para realizar esta tarea, debe ser un administrador de clústeres.


.Paso
. Elimina la configuración de gestión de claves integrada para el SVM de administración:
+
[cols="35,65"]
|===


| Para esta versión de ONTAP... | Se usa este comando... 


 a| 
ONTAP 9,6 y versiones posteriores
 a| 
`security key-manager onboard disable -vserver SVM`



 a| 
ONTAP 9,5 y anteriores
 a| 
`security key-manager delete-key-database`

|===
+
Obtenga más información sobre `security key-manager onboard disable` y `security key-manager delete-key-database` en el link:https://docs.netapp.com/us-en/ontap-cli/search.html?q=security+key-manager["Referencia de comandos del ONTAP"^].

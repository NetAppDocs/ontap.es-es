= Modificar la capacidad del volumen de destino en una relación de DR de SVM de ONTAP
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
A partir de ONTAP 9.20.1, los administradores de almacenamiento y de protección de datos pueden ajustar algunos atributos de capacidad del volumen en un volumen de destino de DR de SVM para mantener los límites de ajuste automático del tamaño del destino alineados con el crecimiento del origen, aumentar la reserva de snapshot para la retención del destino y permitir que los administradores de proveedores de servicios gestionen con precisión a los clientes de DR multi-tenant en función de la capacidad del destino.



[[adjust-the-maximum-size-svm-dr-destination-volumes-can-grow-automatically]]
== Ajustar el tamaño máximo hasta el que los volúmenes de destino de SVM DR pueden crecer automáticamente

.Pasos
. Para modificar el valor máximo de ajuste automático del volumen, introduce el siguiente comando:
+
`volume modify -vserver <dest svm name> -volume <vol name> -max-autosize <integer>`

+
Ejemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -max-autosize 10TB
----




[[adjust-the-minimum-size-svm-dr-volumes-can-shrink-automatically]]
== Ajusta el tamaño mínimo hasta el que los volúmenes SVM DR pueden reducirse automáticamente

. Para modificar el valor mínimo de ajuste automático del tamaño de un volumen, introduce el siguiente comando:
+
`volume modify -vserver <dest svm name> -volume vol1 -min-autosize <integer>`

+
Ejemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -min-autosize 1TB
----




[[change-the-volumes-autosize-mode]]
== Cambiar el modo de ajuste automático del volumen

. Para cambiar el modo de ajuste automático, introduce el siguiente comando:
+
`volume modify -vserver svmdr_dst -volume vol1 -autosize-mode`

+
Ejemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -autosize-mode grow
----




[[adjust-the-amount-of-space-reserved-for-snapshots]]
== Ajustar la cantidad de espacio reservado para las instantáneas

. Para modificar el porcentaje de espacio reservado para las instantáneas, introduce el siguiente comando:
+
`volume modify -vserver <dest svm name> -volume <vol name> -percent-snapshot-space <integer>`

+
Ejemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -percent-snapshot-space 25
----

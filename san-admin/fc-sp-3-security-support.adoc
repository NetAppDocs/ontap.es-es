= Infórmate sobre la compatibilidad de ONTAP con la seguridad FC-SP-3
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partir de ONTAP 9.20.1, ONTAP admite la autenticación y el cifrado del Fibre Channel Security Protocol 3 (FC-SP-3) para los adaptadores de bus de host (HBA) seguros de Broadcom en determinados sistemas ONTAP. FC-SP-3 proporciona cifrado a nivel de hardware y autenticación de dispositivos para ayudar a proteger los datos en tránsito entre los hosts FC y NVMe/FC y los sistemas de almacenamiento ONTAP frente a la interceptación, la manipulación y el acceso no autorizado, a la vez que mantiene el rendimiento y se ajusta a los estándares de seguridad FC T11.

Los siguientes adaptadores HBA seguros de Broadcom son compatibles con FC-SP-3:

* Tarjetas de destino: LPe38104
* Tarjetas iniciadoras: LPe38102 (64G), LPe37102 (32G)


Utiliza la guía link:https://hwu.netapp.com/["NetApp Hardware Universe"^] para comprobar si tu sistema ONTAP concreto es compatible con los HBA necesarios.

También puedes utilizar el `fcp adapter show -fields transport-security-supported` comando para comprobar si tu HBA es compatible con FC-SP-3. El campo *transport-security-supported* es *true* cuando se admite FC-SP-3.



[[enable-fc-sp-3-support]]
== Habilitar la compatibilidad con FC-SP-3

Si tu configuración es compatible con FC-SP-3, puedes habilitarlo cuando link:../networking/create_a_lif.html["cree"] o link:../networking/modify_a_lif.html["modificar"] una interfaz de red (LIF) al establecer  `-fc-transport-security option` en *mandatory* o *preferred*. Establece la opción en *mandatory* para impedir que los hosts que no sean compatibles con FC-SP-3 accedan al sistema de almacenamiento. Establece la opción en *preferred* para que ONTAP intente establecer una conexión FC-SP-3 y siga permitiendo el acceso del host si no se puede establecer FC-SP-3.

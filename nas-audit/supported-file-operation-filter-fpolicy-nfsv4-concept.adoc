= Operaciones de archivo y filtros compatibles de FPolicy para NFSv4 en ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cuando configura su evento de FPolicy, debe tener en cuenta que solo ciertas combinaciones de operaciones y filtros son compatibles para supervisar las operaciones de acceso a archivos NFSv4.

A partir de ONTAP 9.15.1, FPolicy admite el protocolo NFSv4,1.

A partir de ONTAP 9.19.1, los administradores pueden controlar la disponibilidad de NFSv4.2 en el nivel SVM, activando o desactivando el protocolo para máquinas virtuales de almacenamiento individuales usando System Manager, la CLI o la API de REST.

A partir de ONTAP 9.20.1, FPolicy admite la supervisión de eventos de acceso a archivos NFSv4.2, incluidas las nuevas operaciones de archivo para escrituras de atributos extendidos (xattr) y los filtros de etiquetas de seguridad para la actividad de Labeled NFS. Obtén más información sobre link:../nfs-admin/enable-disable-nfs-task.html["habilitar o deshabilitar NFS para las SVMs de ONTAP"].


NOTE: Los filtros de etiquetas de seguridad (`setattr_with_security_label_change` y `getattr_with_security_label_read`) requieren que las etiquetas de seguridad NFSv4.2 (Labeled NFS) estén habilitadas en el SVM. Más información sobre link:../nfs-admin/enable-nfsv42-security-labels-task.html["activar las etiquetas de seguridad de NFSv4.2"]. `getxattr` y `listxattrs` son operaciones de solo lectura y FPolicy no las supervisa.

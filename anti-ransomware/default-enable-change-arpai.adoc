= Gestiona la activación automática de ARP/AI en ONTAP durante las actualizaciones
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:imagesdir: ../media/


[role="lead"]
Al actualizar a ONTAP 9.18.1 o una versión posterior, la protección autónoma contra ransomware con IA (ARP/AI) se activa automáticamente de forma predeterminada en todos los volúmenes nuevos de los sistemas AFF A-series, AFF C-series, ASA y ASA r2 después de un periodo de gracia de 12 horas, siempre que se haya instalado una licencia anti-ransomware. Usa este procedimiento para desactivar la activación automática por defecto durante o después del periodo de gracia, o para cambiar la configuración en cualquier momento después de la actualización.


NOTE: Si utilizas ONTAP 9.15.1 o una versión anterior, consulta link:index.html["Aprenda sobre la protección autónoma contra el ransomware."].


NOTE: Si utilizas ONTAP 9.17.1 o una versión anterior, la activación predeterminada automática a nivel de clúster no se aplica. Puedes configurar la activación predeterminada a nivel de SVM usando link:enable-default-arpai.html["Habilitar ARP/AI de forma predeterminada en los nuevos volúmenes"].


NOTE: Los volúmenes existentes deben ser link:enable-arpai.html["activado manualmente"] para ARP/AI.


NOTE: A partir de ONTAP 9.19.1, la activación predeterminada de ARP/AI se aplica a los clústeres que incluyen SnapMirror synchronous y SnapMirror active sync SAN relationships. En ONTAP 9.18.1, la activación predeterminada se desactivaba para estas configuraciones. Para las relaciones síncronas entre clústeres SnapMirror, la activación predeterminada se activa después de que tanto el clúster de origen como el de destino se actualicen a ONTAP 9.19.1.

.Acerca de esta tarea
La configuración que elijas se puede modificar más adelante. Una vez finalizado el periodo de gracia, siempre tendrás la posibilidad de activar o desactivar la habilitación automática por defecto en cualquier momento:

[source, cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false|true
----
.Pasos
Puedes usar System Manager o la CLI de ONTAP para gestionar la activación automática predeterminada de ARP/AI.

[role="tabbed-block"]
====
.System Manager
--
. Seleccione *Cluster > Settings*.
. Debe realizar una de las siguientes acciones:
+
** Desactivar durante el periodo de gracia activo:
+
... En la sección *Anti-ransomware*, verás un mensaje que indica las horas que quedan para que se active ARP/AI. Selecciona *Don't enable*.
... Selecciona *Desactivar* en el siguiente cuadro de diálogo para confirmar que la activación predeterminada de ARP/AI está desactivada para los nuevos volúmenes.


** Desactivar después del periodo de gracia:
+
... En la sección *Anti-ransomware*, selecciona image:icon_pencil.gif["Icono Editar"].
... Marca la casilla de selección y luego haz clic en *Guardar* para desactivar la activación automática por defecto de ARP/AI en los nuevos volúmenes.






--
.CLI
--
. Comprueba el estado de la activación automática:
+
[source, cli]
----
security anti-ransomware auto-enable show
----
. Desactiva la activación automática por defecto para los nuevos volúmenes:
+
[source, cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false
----

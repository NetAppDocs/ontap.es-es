= Retire un reflejo de ONTAP FabricPool
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible quitar un reflejo de FabricPool si ya no se necesita replicar un almacén de objetos.

.Antes de empezar
El almacén de objetos primario debe estar operativo; de lo contrario, el comando falla.


WARNING: Esta operación elimina de forma permanente todos los objetos del contenedor del almacén de objetos y no se puede deshacer. La eliminación de objetos continúa en segundo plano una vez finalizada la operación de desactivación del espejo. No reutilices ni reasignes el contenedor hasta que haya finalizado el proceso de eliminación en segundo plano.

.Paso
. Quite un reflejo de almacén de objetos en una FabricPool con `storage aggregate object-store unmirror -aggregate` el comando.
+
[listing]
----
cluster1::> storage aggregate object-store unmirror -aggregate aggr1
----

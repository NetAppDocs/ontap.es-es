= Determina las velocidades de puerto de destino FC compatibles con tu sistema ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Los puertos de destino FC se pueden configurar y utilizar para el protocolo FC-NVMe exactamente de la misma forma que se configuran y utilizan para el protocolo FC.

Para obtener el mejor rendimiento y la máxima disponibilidad, debes utilizar la configuración de puertos de destino recomendada que figura en https://hwu.netapp.com["NetApp Hardware Universe"^] para tu sistema ONTAP concreto.

Cada puerto FC integrado y cada puerto del adaptador de expansión se pueden configurar individualmente para las distintas velocidades compatibles. Las velocidades compatibles varían en función de tu sistema ONTAP y de los HBA. Todos los puertos de destino usados por un host determinado deben configurarse a la misma velocidad.

Como práctica recomendada, debes configurar una velocidad común en todos tus puertos de iniciador, switch y destino. Si las velocidades del puerto y del iniciador son diferentes, y no se puede negociar una velocidad común, no se puede establecer una sesión. No se recomienda usar la negociación automática para establecer la velocidad del puerto. La negociación automática puede ralentizar el establecimiento de la sesión y la reconexión después de una interrupción.

Las velocidades compatibles se indican en el NetApp Hardware Universe en *Tarjetas de adaptador compatibles* para cada sistema ONTAP.

.Pasos
. Vaya a link:https://hwu.netapp.com["NetApp Hardware Universe"^].
. Selecciona *Productos*.
. En *Plataformas*, selecciona tu tipo de sistema.
. Selecciona tu sistema concreto y, a continuación, selecciona tu versión de ONTAP.
. Selecciona *Mostrar resultados* y, a continuación, selecciona *Supported Adapter Cards*.
+
Las tarjetas adaptadoras FC aparecen en la sección *Categoría* como “Block Access (Target)” y las velocidades compatibles se indican en la sección *Supported Protocol(s)*.

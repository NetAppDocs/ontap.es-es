= Más información sobre ONTAP Mediator para MetroCluster IP y la sincronización activa de SnapMirror
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediator admite la sincronización activa de SnapMirror y MetroCluster IP, ya que proporciona un almacén persistente y aislado para metadatos de alta disponibilidad (HA), una función de consulta sincrónica del estado de los nodos para facilitar la determinación del quórum, y actúa como proxy de ping para comprobar la actividad de los controladores.

ONTAP Mediator se ejecuta en un host Linux situado en un tercer dominio de fallo, independiente de tus clústeres de ONTAP, donde proporciona un almacén persistente y aislado para los metadatos de alta disponibilidad. ONTAP utiliza este almacén, junto con las funciones de consulta del estado de los nodos y de proxy de ping de Mediator, para supervisar las relaciones de sincronización activa de SnapMirror y las configuraciones IP de MetroCluster.

* ONTAP Mediator utiliza el LIF de gestión de nodos y el LIF de gestión de clúster para comunicarse con cada clúster a través de múltiples rutas redundantes. Esto permite a ONTAP distinguir entre un fallo total del sitio y un único fallo de enlace InterSwitch (ISL).
* En la sincronización activa de SnapMirror, si un clúster pierde la conexión tanto con su par como con ONTAP Mediator, ONTAP considera que el par es inaccesible y puede conmutar automáticamente a la copia superviviente.
* En las configuraciones IP de MetroCluster, ONTAP Mediator facilita una conmutación de sitios automática no planificada asistida por Mediator (MAUSO) al almacenar información de estado sobre los nodos de MetroCluster y ayudar a determinar el curso de acción adecuado durante un fallo.


Para instalar o actualizar la versión local de ONTAP Mediator, consulta el link:https://docs.netapp.com/us-en/ontap-mediator/index.html["Documentación de ONTAP Mediator"^]

Para obtener información sobre ONTAP Cloud Mediator, disponible a partir de ONTAP 9.17.1, consulta link:../snapmirror-active-sync/index.html["Documentación de sincronización activa de SnapMirror"].

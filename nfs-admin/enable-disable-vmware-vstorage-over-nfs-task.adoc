= Habilitar o deshabilitar VMware vStorage sobre ONTAP NFS
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes activar o desactivar la compatibilidad con VMware vStorage a través de NFS en las máquinas virtuales de almacenamiento (SVM) mediante el comando  `vserver nfs modify`. Esta configuración controla las operaciones de VMware VAAI a través de NFS, como la copia de datos descargados y la reserva de espacio.

.Acerca de esta tarea
De forma predeterminada, la compatibilidad con VMware vStorage over NFS está deshabilitada.

A partir de ONTAP 9.20.1, al habilitar VMware vStorage sobre ONTAP NFS, también se admite la reclamación automática de espacio para los almacenes de datos NFSv3 y NFSv4.1 con Thin-Provisioning.

.Pasos
. Comprueba la configuración actual de VMware vStorage sobre NFS para la SVM:
+
`vserver nfs show -vserver vserver_name -fields vstorage`

. Ejecute una de las siguientes acciones:
+
[cols="2*"]
|===
| Si desea... | Introduzca el siguiente comando... 


 a| 
Activar la compatibilidad con VMware vStorage
 a| 
`vserver nfs modify -vserver vserver_name -vstorage enabled`



 a| 
Desactivar la compatibilidad con VMware vStorage
 a| 
`vserver nfs modify -vserver vserver_name -vstorage disabled`

|===
. Comprueba que la configuración esté actualizada:
+
`vserver nfs show -vserver vserver_name -fields vstorage`



.Después de terminar
Para poder utilizar esta funcionalidad, debes instalar el complemento NFS de NetApp para VMware VAAI. La reclamación automática de espacio requiere la versión 3.0 o posterior.

Para conocer los requisitos de host, plug-in e interoperabilidad de VMware, consulta la documentación de NetApp NFS Plug-in for VMware VAAI y NetApp Interoperability Matrix Tool.

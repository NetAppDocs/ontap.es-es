= Ver la información del clúster desde el panel de control de ONTAP System Manager
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
La consola de System Manager ofrece una vista rápida y completa de su clúster de ONTAP desde una única ubicación.

Desde el panel de control de System Manager, puedes consultar información sobre el estado, la capacidad, la red y el rendimiento de tu clúster, incluidas alertas importantes, la eficiencia y la capacidad de los niveles y volúmenes de almacenamiento, el estado y la disponibilidad de los nodos del clúster, las aplicaciones y los objetos más activos, así como las métricas de rendimiento.

A partir de ONTAP 9.19.1, los administradores de SVM pueden supervisar y gestionar sus propias SVM mediante un panel de control dedicado para administradores de SVM en ONTAP System Manager. Para obtener más información, consulta link:task-svm-admin-dashboard-sm.html["Administra y supervisa los SVM con System Manager"].

El panel incluye cuatro paneles que se describen a continuación:



[[view-the-cluster-health]]
== Ver el estado del clúster

En la sección *Health* del dashboard de ONTAP System Manager, puedes consultar información general sobre tu clúster, como su nombre, la versión de ONTAP y la fecha de creación. También puedes consultar el estado general de los nodos del clúster, los errores a nivel de clúster, las advertencias, las alertas y las modificaciones sugeridas para mejorar el rendimiento del clúster.

A partir de ONTAP 9.20.1, se muestra una alerta de estado 30 días antes de que caduque el certificado de un clúster o de una máquina virtual de almacenamiento (SVM). La alerta se actualiza diariamente para mostrar el número de días que quedan hasta la caducidad. Puedes modificar el umbral de alerta predeterminado de 30 días por cualquier número de días entre 0 y 90, desactivarlo para que no se muestren alertas o suprimir las alertas de los certificados ya caducados mientras sigues recibiendo alertas de las próximas caducidades.

* Para ver la información de estado del clúster, selecciona image:icon_arrow.gif["Icono de flecha"] junto a *Health* en el panel de control.
* Para modificar la configuración de caducidad del certificado, selecciona la alerta y, a continuación, selecciona *Configuración del certificado*.




[[view-the-cluster-capacity]]
== Ver la capacidad del clúster

En la sección *Capacidad* del panel de control de ONTAP System Manager, puedes consultar el espacio de almacenamiento de un clúster. Puedes consultar el espacio lógico total utilizado, el espacio físico total utilizado y el espacio en disco disponible.

Puedes registrarte en ActiveIQ para consultar los datos históricos del clúster.

Selecciona image:icon_arrow.gif["Icono de flecha"] junto a *Capacidad* en el panel de control para ver información sobre la capacidad del clúster, incluida una visión general de los niveles asociados a un clúster, como el espacio total, el espacio utilizado y el espacio disponible. También se muestran detalles sobre el rendimiento, las IOPS y la latencia. link:./concepts/capacity-measurements.html["Descubre cómo ONTAP informa sobre el almacenamiento utilizado"].

Puede elegir añadir un nivel local o un nivel de cloud utilizando la vista de capacidad. Para obtener más información, consulte link:task_admin_monitor_capacity_in_sm.html["Ver la capacidad de un clúster"].



[[view-the-cluster-network]]
== Ver la red del clúster

En la sección *Red* del panel de control de ONTAP System Manager, puedes ver los puertos físicos, las interfaces de red y las máquinas virtuales de almacenamiento que forman parte de la red.

La vista Red muestra el tipo de clientes conectados a la red. Cada uno de estos clientes conectados a la red está representado por un número (por ejemplo, «NVMe/FC 16»). Seleccione el número para ver detalles específicos de cada uno de estos elementos de red.

Selecciona image:icon_arrow.gif["Icono de flecha"] junto a *Red* en el panel de control para ver una vista amplia de página completa de la red que abarca puertos, interfaces de red, máquinas virtuales de almacenamiento y hosts en la red.



[[view-the-cluster-performance]]
== Ver el rendimiento del clúster

En la sección *Rendimiento* del panel de control de ONTAP System Manager, puedes consultar estadísticas de rendimiento que te ayudarán a supervisar el estado y la eficiencia de tu clúster ONTAP. Las estadísticas incluyen indicadores clave del rendimiento del clúster, como la latencia, el throughput y las IOPS, que se muestran como gráficos.

La vista Rendimiento muestra las estadísticas de rendimiento en diferentes intervalos de tiempo por día, hora, semana o año. Puede analizar rápidamente el rendimiento del clúster mediante los distintos gráficos e identificar las características que pueden requerir la optimización. Este análisis rápido te ayuda a decidir cómo puede añadir o mover cargas de trabajo. También puede observar los tiempos de uso máximos para planificar posibles cambios.

La vista de rendimiento muestra las métricas de rendimiento totales relacionadas con la latencia, el rendimiento y las IOPS.

A partir de 9.15.1, la vista de rendimiento se mejora para mostrar gráficos para mostrar métricas de lectura, escritura, otra y rendimiento total relacionadas con la latencia, el rendimiento y las IOPS. Otras métricas incluyen las operaciones que no son de lectura ni escritura.

Los valores de rendimiento se actualizan cada 3 segundos y el gráfico de rendimiento se actualiza cada 15 segundos. No se mostrará un gráfico si la información acerca del rendimiento del clúster no está disponible.

Selecciona image:icon-expansion-arrows.png["Icono de expansión"] junto a *Performance* en el panel de control para ver una vista de página completa de las métricas de rendimiento por hora, día, semana, mes y año. También puedes descargar un informe de las métricas de rendimiento en tu sistema local.

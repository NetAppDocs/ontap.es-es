= Directrices sobre la duración de las actualizaciones de ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debería planificar al menos 30 minutos para completar los pasos preparatorios para una actualización de ONTAP, 60 minutos para actualizar cada par de alta disponibilidad y al menos 30 minutos para completar los pasos posteriores a la actualización.


NOTE: Si utilizas NetApp Encryption con un servidor externo de gestión de claves y el Key Management Interoperability Protocol (KMIP), debes tener en cuenta que la actualización de cada par de HA durará más de una hora. Este tiempo adicional no se aplica a una actualización no disruptiva automatizada que se inicia a partir de ONTAP 9.20.1 cuando el clúster utiliza un gestor de claves KMIP externo, no está en una configuración MetroCluster y el partner de HA puede proporcionar las claves. A partir de ONTAP 9.20.1, esos clústeres restauran las claves desde el partner de HA. Consulta xref:../encryption-at-rest/configure-external-key-management-overview-concept.html#intracluster-key-sharing[intercambio de claves dentro del clúster]. La actualización a ONTAP 9.20.1 sigue restaurando las claves desde el servidor de claves, así que ten en cuenta que esa actualización tardará más de una hora por cada par de HA.

Estas directrices de duración de la actualización se basan en configuraciones y cargas de trabajo típicas. Puede usar estas directrices para estimar el tiempo que se necesita para realizar una actualización no disruptiva en su entorno. La duración real del proceso de actualización dependerá del entorno individual y del número de nodos.

= Compatibilidad de ONTAP LIF con los tipos de puerto
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Los LIF pueden tener diferentes características para admitir distintos tipos de puertos. Los LIF pueden estar alojados en un puerto físico o lógico en un IPspace. Cada puerto está asociado con un solo IPspace.


NOTE: Cuando se configuran las LIF de interconexión de clústeres y gestión en la misma subred, es posible que el tráfico de gestión esté bloqueado por un firewall externo y que se produzca un error en las conexiones de AutoSupport y NTP. Puede recuperar el sistema ejecutando `network interface modify -vserver _vserver name_ -lif _intercluster LIF_ -status-admin up|down` el comando para alternar la LIF de interconexión de clústeres. Sin embargo, debe configurar la LIF entre clústeres y la LIF de gestión en subredes diferentes para evitar este problema.

La siguiente tabla resume los tipos de LIF, los tipos de puerto con los que son compatibles y su comportamiento en caso de conmutación por error o migración.

[cols="30,70"]
|===


| LUN | Descripción 


| LIF del clúster  a| 
Una LIF que se utiliza para transportar el tráfico intraclúster entre nodos de un clúster.

* Las LIF de clúster siempre deben crearse en puertos de clúster.
* Las LIF de clúster pueden realizar una conmutación por error entre puertos de clúster del mismo nodo, pero no pueden migrarse ni conmutarse por error a un nodo remoto. Cuando un nuevo nodo se une a un clúster, las direcciones IP se generan automáticamente. Sin embargo, si quieres asignar direcciones IP manualmente a las LIF del clúster, debes asegurarte de que las nuevas direcciones IP estén en el mismo rango de subred que las LIF existentes del clúster.




| LIF de gestión de clústeres  a| 
Un LIF que ofrece una única interfaz de gestión para todo el clúster.

* Un LIF de gestión del clúster puede realizar una conmutación por error a cualquier nodo del clúster. No puede realizar una conmutación por error a puertos de clúster ni a puertos interclúster.




| LIF de datos  a| 
Un LIF asociado a una máquina virtual de almacenamiento (SVM) y que se utiliza para comunicarse con los clientes.

* Cada SVM está asociada a un IPspace específico. Las SVM de datos suelen estar en el IPspace "Default", aunque no necesariamente.
* Puedes alojar varias LIF de datos en un puerto. Estas LIF de datos pueden migrar o conmutar por error en todo el clúster. Puedes modificar una LIF de datos para que funcione como una LIF de gestión de SVM cambiando su política de firewall a mgmt.
* Las sesiones establecidas con servidores NIS, LDAP, Active Directory, WINS y DNS usan LIF de datos.




| LIF de interconexión de clústeres  a| 
Una LIF que se utiliza para la comunicación entre clústeres, copias de seguridad y replicación.

* Debes crear una LIF entre clústeres en cada nodo del clúster antes de que se pueda establecer una relación de paridad entre clústeres. Estas LIF solo pueden conmutar por error a puertos en el mismo nodo. No pueden migrarse ni conmutar por error a otro nodo del clúster.




| LIF de gestión de nodos  a| 
Un LIF que proporciona una dirección IP dedicada para gestionar un nodo concreto de un clúster.

* Los LIF de gestión de nodos se crean en el momento de crear el clúster o de unirse a él. Estos LIF se utilizan para el mantenimiento del sistema, por ejemplo, cuando un nodo se vuelve inaccesible desde el clúster.




| Dirección LIF de gestión de SVM  a| 
Un LIF que proporciona conectividad administrativa a un SVM, lo que permite realizar operaciones de gestión (a menudo a través del puerto 443) y prestar servicios relacionados con la gestión de ese SVM.

* Cada SVM está asociada a un IPspace específico.
* La LIF puede migrar o conmutar por error a otro nodo o puerto según la política de conmutación por error.
* Puedes alojar varias LIF de gestión de SVM en un puerto.
* Un LIF de gestión de SVM resulta útil cuando trabajas en un entorno de multi-tenancy.




| LIF VIP  a| 
Una LIF de IP virtual (VIP) es cualquier LIF de datos creada en un puerto VIP.

Para obtener más información, consulta link:../networking/configure_virtual_ip_vip_lifs.html["Configurar las LIF de IP virtual (VIP)"].

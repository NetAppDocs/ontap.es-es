= Desactiva FC-SP-3 en las LIF de FC antes de revertir desde ONTAP 9.20.1
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partir de ONTAP 9.20.1, ONTAP admite la autenticación y el cifrado mediante Fibre Channel Security Protocol 3 (FC-SP-3) usando adaptadores de bus de host seguros (HBA) de Broadcom con sistemas AFF y FAS. Si las interfaces de red (LIF) FC o NVMe/FC están habilitadas para FC-SP-3 en tu sistema ONTAP, debes desactivarlas antes de revertir a ONTAP 9.19.1.

.Pasos
. Comprueba la configuración de FC-SP-3 en tus LIFs:
+
[source, cli]
----
network interface show -fields fc-transport-security
----
. Si el estado del campo *transport-security-state* no está disponible, no es necesario realizar ninguna acción adicional. Si el estado es *mandatory* o *preferred*, cámbialo a *disabled*:
+
[source, cli]
----
network interface modify -vserver <vserver_name> -lif <lif_name> -fc-transport-security disabled
----
. Comprueba que FC-SP-3 esté desactivado en los LIFs que estaban activados anteriormente:
+
[source, cli]
----
network interface show -fields fc-transport-security
----

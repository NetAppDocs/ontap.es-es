= Configurar alertas de caducidad de contraseñas de usuario de ONTAP en System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partir de ONTAP 9.20.1, si el rol asociado a una cuenta de usuario está configurado para alertas de caducidad de contraseña, el usuario recibe una alerta de banner en la parte superior de la página de System Manager inmediatamente después de iniciar sesión, начиная 14 días antes de que caduque la contraseña. La alerta se actualiza cada vez que el usuario inicia sesión para mostrar el número de días que quedan hasta que caduque la contraseña. Puedes configurar las alertas de caducidad al añadir o editar un rol de administrador.

.Pasos
. Seleccione *Cluster > Settings*.
. Selecciona image:icon_arrow.gif["icono de flecha"] junto a *Users and roles*.
. Configura alertas de caducidad de contraseñas al añadir o modificar un rol de usuario.
+
** Para configurar esto al añadir un rol de usuario, en *Roles*, selecciona image:icon_add.gif["añadir icono"]. Introduce un nombre para el rol y, a continuación, selecciona el periodo de caducidad de la contraseña y una alerta de caducidad de la contraseña.
** Para configurarlo al editar un rol de usuario, en *Roles*, selecciona el rol de usuario. Selecciona *Edit* y, a continuación, selecciona el periodo de caducidad de la contraseña.
** Seleccione *Agregar*.




.Resultado
Recibes una alerta de banner en la parte superior de la página en System Manager inmediatamente después de iniciar sesión, a partir del número de días seleccionado antes de que caduque la contraseña. La alerta se actualiza cada vez que inicias sesión para mostrar el número de días que quedan hasta que caduque la contraseña.
